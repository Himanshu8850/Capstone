# Amendment AMD-003: Writer biographies, five books per writer, seeded reviews, themed covers, detail-page layout fix

**Status: requested by the project owner, 2026-11-18.** Extends AMD-002; no new endpoint and no change to the number of operations (31).

## What changed

- **Writer biography**: new table `author_profile(name PK, bio varchar(600))` (Flyway `V3__author_profile.sql`). `BookDetail` gains the optional `authorBio` field (OpenAPI 1.2.0). "About the writer" shows the biography under the name. The biography is plain text and is rendered as text (no HTML).
- **Seed data**: the 60 books belong to 12 writers with five books each; every writer has a 50-word biography (`R__seed_writers.sql`). Each book has five seeded reviews from ten seeded reader customers (`R__seed_reviews.sql`, `reader1..10@seed.bookygeek.invalid`, an unusable password hash, so nobody can log in as them). All seed files are generated by `scripts/generate-seed-data.mjs` from `scripts/seed-writers.mjs`.
- **Covers**: 60 front and 60 back covers are generated from the book title, author and description (`frontend/scripts/generate-covers.mjs`).
- **Reviews bug**: reviews returned 500 in a local environment because the `review` table was created by a different database role than the application role. Not a code defect; the owner of the table was corrected. Flyway must run as the application role.
- **Layout fix**: the "Related Reads" column no longer stretches the first grid row, so "About the writer" and "Reviews" follow the book details directly.
